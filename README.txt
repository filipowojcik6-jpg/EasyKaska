Money Mod (Fabric, Minecraft 1.21.11) - TYLKO WIZUALNY, tylko po stronie klienta.
Klawisz Y -> GUI z suwakiem 100 000 - 10 000 000. Mod podmienia liczbę w linii
scoreboardu/taba, która zawiera słowo Money/Balance/Saldo/Pieniądze/Coins/Kasa lub znak $.
Nic nie wysyła na serwer, widzisz to tylko Ty.

BUDOWANIE: wrzuć zawartość tego folderu na GitHub - .jar zbuduje się sam (zakładka Actions).

JEŚLI NIE PODMIENIA: plik config/moneymod.json ma pole "pattern" (regex).
Pierwsza grupa łapiąca ( ... ) to liczba do podmiany. Dostosuj do wyglądu linii na serwerze.
